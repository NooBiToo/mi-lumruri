# Установка на Xiaomi BE7000

Понадобятся BE7000 (RC06) с прошивкой 1.1.38, действующий root-доступ по SSH из домашней сети, установочный TAR и приложение для одноразовых кодов. Штатная релизная прошивка обычно поставляется с выключенным SSH. Для подключения через VPN понадобятся параметры вашего сервера.

## 1. Подготовьте пакет и проверьте роутер

Для текущей версии пакет называется `mi-trusttunnel-0.1.0-stage12.tar`. GitHub Release с этим архивом пока отсутствует. При самостоятельной сборке файл появится в `out/package/`. Перед установкой сверьте SHA-256 архива с отчётом своей доверенной сборки. [Как собрать пакет](build.md)

Откройте терминал на компьютере. В примерах адрес роутера — `192.168.31.1`. Подставьте свой LAN-адрес во все команды и в адрес панели.

```sh
ssh root@192.168.31.1 "df -k /data /tmp"
```

Установленные файлы занимают около 18,5 МБ во внутренней памяти, распакованные — около 72 МБ в RAM. Установщик дополнительно требует 2 МиБ свободного места в `/data` и 16 МиБ в `/tmp`. При копировании и распаковке пакета в `/tmp` также лежат сам архив и его содержимое. Для подробной диагностики можно выполнить [проверку совместимости в режиме чтения](../tools/device/preflight.sh).

## 2. Установите по SSH

На компьютере откройте каталог с готовым TAR и выполните:

```sh
scp -O mi-trusttunnel-0.1.0-stage12.tar root@192.168.31.1:/tmp/mitt-install.tar
ssh root@192.168.31.1
```

В SSH-сессии на роутере выполните блок целиком. Ключ `-O` в предыдущей команде включает протокол SCP, который понимает штатный Dropbear.

```sh
stage=$(mktemp -d /tmp/mitt-install.XXXXXX) &&
  tar xf /tmp/mitt-install.tar -C "$stage" &&
  cd "$stage/mi-trusttunnel" &&
  sh install.sh
```

После успешной установки настройте вход:

```sh
sh /data/mi-trusttunnel/mitt-boot.sh auth init
sh /data/mi-trusttunnel/mitt-boot.sh auth confirm
openssl x509 -in /data/mi-trusttunnel/etc/tls/cert.pem -noout -fingerprint -sha256
```

Задайте пароль, добавьте выданный секрет в приложение TOTP и подтвердите код. Сохраните одноразовые коды восстановления. Откройте **`https://192.168.31.1:8443/`** из домашней сети. При первом входе сверьте SHA-256 сертификата в браузере с отпечатком из SSH-сессии.

## 3. Создайте первое правило

1. В **«Устройства и сети»** добавьте домашнюю сеть и устройство. Для устройства можно заполнить форму из списка DHCP. Для правила на весь SSID укажите его фактический интерфейс на мосту.
2. В **«Профили»** добавьте VPN-сервер и введите параметры подключения.
3. В **«Новое правило»** выберите устройство, укажите домен и выберите VPN-профиль. Нажмите **«Проверить и показать»**, проверьте маршрут и сохраните правило.
4. В **«Состояние»** нажмите **«Применить настройки»**, затем **«Обновить»**. Откройте выбранный сайт с этого устройства. Если у вас есть доступ к журналу VPN-сервера, проверьте появление подключения.

## Обновление и откат

Для обновления скопируйте новый TAR и повторите шаг 2 до настройки входа. Существующие настройки и второй фактор сохраняются. Потребуется место ещё для одного релиза. Обновление должно быть подписано тем же ключом, что и первая установка.

Чтобы посмотреть состояние работающей службы, выполните по SSH:

```sh
sh /data/mi-trusttunnel/mitt-boot.sh status
```

Для отката выполните **одну** команду из каталога распакованного пакета, где находится `install.sh`. Если после перезагрузки каталог исчез, снова скопируйте и распакуйте TAR. Запускать установку для отката не требуется.

```sh
sh install.sh rollback
```

Откат доступен после установки второй версии. Для удаления программы с сохранением настроек выполните в том же каталоге `sh install.sh uninstall`.

## Если вход не получается

- **SSH выдаёт отказ в соединении.** Проверьте LAN-адрес и доступность SSH на текущей прошивке. Установщик запускается уже внутри SSH-сессии.
- **Установщик сообщает о нехватке места.** Он выводит требуемый и доступный объём отдельно для `/data` и `/tmp`. Проверьте оба раздела командой из шага 1.
- **Панель отклоняет код после перезагрузки.** Проверьте время командой `date -u`. Дождитесь синхронизации часов или воспользуйтесь одноразовым кодом восстановления. Уже использованный TOTP повторно не принимается.
