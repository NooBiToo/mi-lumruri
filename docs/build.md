# Сборка и проверка

Собирайте на компьютере. Для команд ниже подойдёт Ubuntu x86_64 с Bash, Node.js 22.12 или новее, npm, Python 3.12+, curl, компилятором для хоста и утилитами apt. Понадобится интернет для первой загрузки зависимостей. Команды выполняются из корня проекта.

## Установочный пакет

```sh
tools/setup-tools.sh
tools/lab/fetch-dns.sh
tools/lab/fetch-zapret.sh
tools/cargo.sh build --release --locked --target aarch64-unknown-linux-musl
(cd panel && npm ci && npm run build)
node tools/package.mjs
```

Готовый TAR и JSON-отчёт с SHA-256 находятся в `out/package/`. На роутер переносится **TAR**. Для последующих обновлений сохраните закрытый ключ своей сборки из `.tools/keys/` в защищённом месте. При первом запуске сборщик создаёт его автоматически, а роутер закрепляет соответствующий открытый ключ при установке. [Инструкция для роутера](guide.md)

## Тесты

```sh
tools/cargo.sh test --locked
(cd panel && npm ci && npm test && npm run build)
```

Полный прогон на подготовленном стенде запускается командой `bash tools/check-all.sh`. Он включает HTTPS-стенд, сборку ARM64, проверку пакета и сетевые лаборатории. Проверяйте также сообщения о пропусках: без QEMU или движков часть проверок пропускается. Подготовка лабораторий и результаты по протоколам описаны в [техническом отчёте](../VERTICAL-SLICE.md).

| Каталог | Содержимое |
| --- | --- |
| `controller/` | Rust-контроллер конфигурации и административная утилита |
| `panel/`, `stand/` | Веб-панель и локальный HTTPS-стенд |
| `package/` | Установщик, служба и начальные настройки |
| `tools/lab/` | Изолированные сетевые сценарии |
