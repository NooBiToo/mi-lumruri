# Простая панель по образцу TrustTunnelOpenWrt

## Зачем

Текущая панель показывает внутреннюю модель контроллера: правила «источник × назначение × действие», группы, категории, сети с мостами и портами, идентификаторы. Для домашнего пользователя это непонятно. Нужен интерфейс, который отвечает на три вопроса: к какому серверу подключаться, какие сайты пускать через VPN и для каких устройств.

## Цели и не-цели

- Цель: настройка с нуля за несколько минут без знания мостов, портов, MAC и идентификаторов.
- Цель: выбор сайтов галочками по готовым спискам itdoginfo/allow-domains плюс свои домены.
- Не цель: гибкие правила «устройство × группа × действие» в панели. Модель правил остаётся в контроллере как движок, но панель её не показывает.
- Не цель: блокировка отдельных сайтов в интерфейсе (блокировка рекламы остаётся).
- Анти-цель: экран, на котором пользователь должен понимать устройство сети роутера.

## Подходы

1. **Как в TrustTunnelOpenWrt — выбран.** Четыре экрана, панель сама собирает правила контроллера из ответов пользователя.
2. Оставить правила и упростить подачу мастером «кто → какие сайты → как». Отклонён: сохраняет сложную модель, мастер лишь растягивает её на шаги.
3. Один экран «сервер + домены для всей сети». Отклонён: теряются выбор устройств, готовые списки и Zapret.

## Экраны

1. **Состояние.** Подключён ли туннель, сколько сайтов и устройств идёт через VPN, когда обновлялись списки. Кнопка «Выключить VPN» / «Включить VPN».
2. **Сервер.** Поле «Вставьте конфигурацию клиента» (файл, который выдаёт `trusttunnel_endpoint … --format toml`) — поля заполняются сами; ниже те же поля вручную (адрес, порт, имя сервера, логин, пароль, HTTP/3, anti-DPI, сертификат). Переключатель «Если сервер недоступен: блокировать эти сайты / пускать напрямую».
3. **Сайты.**
   - Режим: «Только выбранные сайты через VPN» (по умолчанию) или «Всё через VPN, кроме исключений».
   - Галочки сервисов и категорий из списков itdoginfo (YouTube, Instagram и Facebook, Discord, Telegram, ChatGPT и Google AI, TikTok, X, «Заблокированное в России» и т. д.). У сервисов с подсетями (Telegram, Discord, Meta…) подсети подключаются той же галочкой.
   - Свои домены и исключения — текстовыми полями, по домену в строке.
   - «Остальные сайты: напрямую / напрямую с Zapret».
4. **Устройства.** «Все устройства дома» (по умолчанию) или «Только выбранные» — галочки по списку подключённых устройств из аренд DHCP (имя, IP, MAC мелким шрифтом); можно переименовать устройство.
5. **Дополнительно** (свёрнуто, отдельный пункт меню): блокировка рекламы, DNS-сервер для сайтов через VPN, стратегия Zapret, вход в панель (TOTP).

Каждое сохранение сразу ставит заявку на применение; отдельной кнопки «Применить» нет. Вверху всегда строка состояния туннеля.

## Как ответы превращаются в настройки контроллера

Панель пишет конфигурацию канонического вида через существующий API:

- категории `svc-<имя>` (домены) и `svc-<имя>-ip` (подсети IPv4) для отмеченных списков;
- группа `vpn-sites`: отмеченные категории и свои домены (`domain_suffix`); группа `vpn-except`: исключения;
- сеть `home`: мост и подсеть LAN роутера (берутся с роутера автоматически, новый маршрут API `/router` читает `network.lan` из uci);
- режим «выбранные сайты»: правило (вся LAN или каждое выбранное устройство) → `vpn-sites` → профиль; `default_action` = напрямую или напрямую с Zapret;
- режим «всё через VPN»: правило → `vpn-except` → напрямую (или с Zapret); `default_action` = профиль (для выбранных устройств — правила по устройствам);
- «Выключить VPN» — все правила `enabled: false`, `default_action` напрямую (галочки сохраняются).

Если конфигурация на роутере не похожа на канонический вид (изменена вручную через CLI), панель показывает это и предлагает привести её к простому виду.

## Списки

- Снимок списков itdoginfo (Services, Categories, `Russia/inside-raw`, Subnets/IPv4 соответствующих сервисов) кладётся в пакет при сборке, закреплённый по коммиту и SHA-256, с файлом каталога (название, файлы доменов и подсетей).
- Служба роутера раз в сутки пробует скачать обновление с `raw.githubusercontent.com` (curl или wget стока); проверяет формат тем же разбором категорий; при ошибке оставляет прежние списки. Обновлённые списки лежат в `/data`, при отсутствии — используются из пакета. После обновления — повторное применение.
- API `/lists`: каталог, что выбрано, дата снимка и последнего обновления.

## Zapret: готовые стратегии и подбор одной кнопкой

Образец — [Zapret-Manager](https://github.com/StressOzz/Zapret-Manager) (Apache-2.0; стратегии берутся с указанием авторства в NOTICE).

- **Работает сразу.** По умолчанию стратегия «Автоматически»: круговой режим zapret2 (`circular`) — nfqws2 сам переключает стратегии для сайта, соединения с которым срываются (после 3 неудач). Наборы из Zapret-Manager: общий (v1–v10 по кругу), YouTube (Yv по кругу), Discord (TLS и голос по UDP), YouTube по QUIC. Пользователю ничего настраивать не нужно.
- **Кнопка «Подобрать».** Роутер проверяет стратегии в стороне: отдельный экземпляр nfqws2 на своей очереди, проверочные запросы `curl` стока с отдельного диапазона портов отправителя — клиенты сети в это время работают на прежней настройке. Цели: YouTube (сайт, API, видеоузел), Discord, набор CDN и хостингов (как у dpi-detector); сначала контроль без Zapret. Адрес открыт, если сервер ответил кодом, кроме 451, и ответ не оборвался на 16–20 КБ. Победитель — больше открытых целей; применяется, только если лучше контроля, затем перепроверка и откат, если стало хуже. Прогресс и итог («Открылось 47 из 54, без Zapret — 12») видны в панели.
- **В панели** (экран «Сайты», блок «Остальные сайты»): «Напрямую» / «Напрямую с обходом блокировок (Zapret)»; под ним «Стратегия: Автоматически (рекомендуется)» или найденная подбором, кнопка «Подобрать», дата и результат последнего подбора.
- **Что меняется в движке:** в пакет добавляются все Lua-библиотеки zapret2 (в т. ч. `zapret-auto` для кругового режима), fake-файлы и списки хостов YouTube/Discord; nfqws2 получает несколько профилей (`--new`) с фильтрами портов и списков; в плане mi-tt-admin очередь NFQUEUE расширяется на UDP (QUIC, голос Discord) и на проверочный трафик роутера в mangle OUTPUT. Zapret действует на трафик LAN, идущий напрямую; сайты из VPN-списка в него не попадают.

## Ограничения

- Панель больше не умеет правила вида «приставка → блокировать» и разные действия для разных сетей; это остаётся в CLI.
- Гостевые сети не участвуют (как в TrustTunnelOpenWrt).

## Решения на усмотрение исполнителя

- Набор и названия сервисов в каталоге (по списку itdoginfo, человеческие названия по-русски).
- Внешний вид: на PrimeVue 4.5.5, текущая палитра и шрифт, но без «маршрутов» и счётчиков; крупные понятные переключатели, один столбец.
- Разбор вставленного конфига сервера — в панели (TypeScript), формат проверяется по полям `client.toml`.
